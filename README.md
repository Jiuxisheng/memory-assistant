# Memory Assistant

A personal memory assistant app for recording life events using the 5W framework (Who, What, When, Where, Why).

## Features

- Chat-style input interface
- Event categorization with color coding
- Timeline view with chronological sorting
- Local data persistence
- Category filtering

## Download

Get the latest APK from the [Releases](../../releases) page.

## Build

### Local Build
```bash
flutter pub get
flutter build apk --release
```

### GitHub Actions
APK is automatically built on every push to main branch.
